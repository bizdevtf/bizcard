# 아이폰 단축어: 사원증 태그 → 출입 이력 자동 기록

사원증을 아이폰에 갖다 대면 **구글 폼이 열리기만 하는 게 아니라**,
현재 날짜·시간이 자동으로 채워져 **제출까지 끝나는** 단축어 설정 가이드.

대상 폼:
`https://docs.google.com/forms/d/e/1FAIpQLSd6TI7M14M-mn_dqBStktVH9T4OxXl6zRfd17PbLRqqCFrW_A/viewform`

동작 원리: 구글 폼은 `.../viewform` 대신 `.../formResponse` 주소에
`entry.<필드ID>=<값>` 형태로 값을 붙여 호출하면 **화면 없이 응답이 접수된다.**
단축어가 현재 날짜/시간으로 이 주소를 만들어 호출하고 알림만 띄운다.

- **방식 A (권장)** — 백그라운드 자동 제출. 태그 → "출입 기록 완료" 알림. 브라우저가 안 뜬다.
- **방식 B** — 값이 다 채워진 폼을 Safari로 열고 제출 버튼만 탭.
  로그인이 필요한 폼(사내 계정 제한, 이메일 자동 수집)은 이 방식만 동작한다.

---

## 0단계 (필수). 폼의 필드 ID(entry ID) 알아내기 — 1회

단축어가 어느 칸에 무엇을 넣을지 알려면 각 질문의 내부 ID가 필요하다.

### 폼 편집 권한이 있는 경우 (가장 쉬움)

1. 폼 **편집 화면**을 연다 (`.../edit`)
2. 우측 상단 **⋮ (더보기)** → **사전 입력된 링크 가져오기**
3. 미리보기 폼이 뜨면 각 칸에 **알아보기 쉬운 임시값**을 넣는다
   - 날짜 칸 → `2026-08-06`
   - 시간 칸 → `09:00`
   - 구분 칸(출근/퇴근) → `출근` 선택
   - 이름 칸 → 본인 이름
4. 하단 **링크 가져오기** → **링크 복사**

복사된 링크는 이런 모양이다:

```
https://docs.google.com/forms/d/e/1FAIpQLSd6TI7M14M-mn_dqBStktVH9T4OxXl6zRfd17PbLRqqCFrW_A/viewform?usp=pp_url
  &entry.1234567890=2026-08-06
  &entry.987654321=09:00
  &entry.555555555=%EC%B6%9C%EA%B7%BC
```

여기서 `entry.1234567890` = 날짜 칸, `entry.987654321` = 시간 칸,
`entry.555555555` = 구분 칸이다. **이 링크를 메모해 두면 아래 작업이 전부 끝난다.**

### 편집 권한이 없는 경우 — "ID 추출기" 단축어 (아이폰만으로 가능)

회사 계정이 소유한 폼이면 **⋮ 메뉴에 "사전 입력된 링크 가져오기"가 아예 없다.**
이때는 폼 HTML을 직접 읽어 ID를 뽑는 단축어를 **한 번만** 만들어 쓰면 된다.
PC도, 편집 권한도 필요 없다.

단축어 앱 → `+` → 이름 **"폼 ID 추출"**:

**① URL 콘텐츠 가져오기** (Get Contents of URL)

- URL:
  ```
  https://docs.google.com/forms/d/e/1FAIpQLSd6TI7M14M-mn_dqBStktVH9T4OxXl6zRfd17PbLRqqCFrW_A/viewform
  ```
- 방법: **GET** (기본값)

**② 텍스트 일치** (Match Text)

- 정규식 칸에 아래를 입력 (대소문자 구분은 꺼 둔다)
  ```
  entry\.[0-9]+(_[a-z]+)?
  ```
- 대상: ①의 `URL 콘텐츠`

**③ 텍스트 결합** (Combine Text) — 대상 `일치`, 구분자 **새로운 줄**

- ②의 결과 변수 이름은 한국어 단축어에서 **`일치`** 다 (영문판 `Matches`).
- 변수를 탭하면 "유형" 선택 팝업이 뜨는데 **"텍스트 일치"에 체크된 기본값 그대로** 두면 된다.
  (`텍스트`·`인덱스`·`패턴` 등은 매치 하나의 부가 정보라 여기서는 쓰지 않는다)

**④ 결과 보기** (Show Result) — 또는 **"클립보드에 복사"** 를 쓰면 붙여넣기 편하다

실행하면 이런 목록이 나온다:

```
entry.1847392015
entry.1847392015
entry.2093847561
entry.774418823_year
entry.774418823_month
entry.774418823_day
```

읽는 법:

- **같은 ID가 2~3번 반복**되는 건 정상이다 (숨은 필드 때문). 중복은 무시한다.
- 나오는 **순서가 폼의 질문 순서**와 같다. 위에서부터 폼 화면의 질문에 하나씩 대응시키면 된다.
- `_year` / `_month` / `_day` 가 붙어 나오면 그 질문은 **날짜 유형**,
  `_hour` / `_minute` 면 **시간 유형**, 아무것도 안 붙으면 **단답형 또는 객관식**이다.
  (즉 이 목록만 보면 질문 유형까지 한 번에 알 수 있다)

> **결과가 비어 있다면** 그 폼은 로그인이 필요한 폼이다.
> 단축어 요청에는 로그인 쿠키가 없어 구글 로그인 페이지 HTML이 돌아오기 때문이다.
> 이 경우 자동 제출(방식 A)도 어차피 불가능하므로 **방식 B**로 가고,
> ID는 사파리에서 폼을 연 뒤 관리자에게 사전 입력 링크를 요청해 받는다.

**객관식/드롭다운의 옵션 텍스트**는 이 방법으로 안 나오므로, 폼 화면을 눈으로 보고
`출근` / `퇴근` 처럼 **띄어쓰기까지 똑같이** 옮겨 적으면 된다.

### 이 폼("사무실 퇴실 점검 리스트")의 확정된 필드 ID

추출 결과로 확인된 실제 값. 위 추출 과정을 다시 할 필요 없이 그대로 쓰면 된다.

| 순서 | 질문 | 유형 코드 | entry ID | 파라미터 형식 |
|---|---|---|---|---|
| 1 | 층 | `2` 객관식 | `127798583` | `entry.127798583=16층` |
| 2 | 퇴실 일자 | `9` 날짜 | `1424655425` | `entry.1424655425_year` / `_month` / `_day` |
| 3 | 퇴실 시간 | `10` 시간 | `1529739954` | `entry.1529739954_hour` / `_minute` |
| 4 | 퇴실 점검 항목 체크 | `4` 체크박스 | `1757192500` | `entry.1757192500=값` (항목 수만큼 반복) |
| 5 | 퇴실자 이름 | `0` 단답형 | `2054172205` | `entry.2054172205=홍길동` |
| 6 | 확인 서명 문항 | `2` 객관식 | `573820476` | `entry.573820476=값` |

> 유형 코드: `0` 단답형, `1` 장문형, `2` 객관식, `3` 드롭다운, `4` 체크박스,
> `9` 날짜, `10` 시간. `FB_PUBLIC_LOAD_DATA_` 안에 질문 제목 바로 뒤에 나온다.

**체크박스(항목 4)** 는 여러 값을 보낼 때 **같은 키를 반복**한다:
`&entry.1757192500=항목A&entry.1757192500=항목B&entry.1757192500=항목C`

> 이 폼은 "점검 항목을 모두 확인하였다"는 **확인 서명** 성격이므로,
> 체크박스를 자동으로 채워 백그라운드 제출(방식 A)하면 실제 점검 없이도
> 기록이 남는다. **방식 B**(값이 다 채워진 폼을 열고 본인이 제출)를 권장한다.

### 확정된 선택지 값

| 질문 | 선택지 (글자 그대로 일치해야 함) |
|---|---|
| 층 (`127798583`) | `16층` `17층` `18층` `19층` |
| 점검 항목 (`1757192500`) | `멀티탭 전원 차단 확인` / `공용 공간 및 회의실 전자기기 확인` / `창문 및 출입문 잠금 확인` / `냉/난방기 전원 OFF` / `사무실 내 모든 조명 소등 확인` / `경비 시스템 설정 확인` |
| 확인 서명 (`573820476`) | `확인했습니다` |

## 완성본 — 이 폼 전용 단축어 (액션 4개)

추출기가 로그인 없이 폼 HTML을 받아왔으므로 이 폼은 **공개 폼**이고, 방식 A·B 모두 가능하다.
아래는 **방식 B**(값이 다 채워진 폼을 열고 본인이 제출) 기준이며, 맨 아래에 방식 A 전환법이 있다.

단축어 앱 → `+` → 이름 **"퇴실 점검"**.

### ① 현재 날짜

### ② 날짜 포맷 지정

- 대상: `현재 날짜`
- **날짜 포맷: 사용자 설정** → 포맷 문자열에 아래를 **그대로** 입력
  (작은따옴표 안은 그대로 출력되는 글자, 밖은 날짜 기호다. 따옴표 하나라도 빠지면 깨진다)

```
'entry.1424655425_year='yyyy'&entry.1424655425_month='M'&entry.1424655425_day='d'&entry.1529739954_hour='H'&entry.1529739954_minute='m
```

- 결과 변수 이름을 **`날짜시간`** 으로 지정
- 실행하면 `entry.1424655425_year=2026&...&entry.1529739954_minute=30` 한 줄이 통째로 만들어진다.
  액션 6개를 쓸 필요가 없다.

> 이 한 줄이 안 먹으면 **「날짜 포맷 지정」을 5개**로 나눠 각각 `yyyy` `M` `d` `H` `m`을
> 뽑아 변수 `연` `월` `일` `시` `분`으로 두고, ③ 텍스트에서 직접 조립해도 결과는 같다.

### ③ 텍스트 — URL 조립

아래를 **한 줄로** 붙여넣고, 맨 끝 `<날짜시간>` 자리에 ②의 변수 `날짜시간`을 **삽입**한다.
한글 값은 미리 퍼센트 인코딩해 두었으므로 공백·슬래시 때문에 깨질 일이 없다.

```

```

고쳐야 할 두 군데:

| 자리 | 바꿀 값 |
|---|---|
| `entry.127798583=16%EC%B8%B5` | 본인 층으로. 16층 `16%EC%B8%B5` / 17층 `17%EC%B8%B5` / 18층 `18%EC%B8%B5` / 19층 `19%EC%B8%B5` |
| `entry.2054172205=[이름]` | `[이름]`을 지우고 본인 이름 입력 (한글 그대로 입력해도 iOS가 알아서 인코딩한다) |

### ④ URL 열기 (Open URLs) — 대상 ③의 `텍스트`

실행하면 Safari에 폼이 뜨고 **층·일자·시간·점검 6항목·이름·확인 서명이 전부 체크된 상태**다.
실제로 사무실을 둘러본 뒤 하단 **제출**만 누르면 끝난다.

### 방식 A(제출까지 자동)로 바꾸려면

③의 URL에서 두 군데만 고치고 ④를 교체한다.

1. `/viewform?usp=pp_url&` → `/formResponse?`
2. 맨 끝 `<날짜시간>` 뒤에 `&submit=Submit` 추가
3. ④「URL 열기」→「**URL 콘텐츠 가져오기**」(GET)로 교체, 뒤에 「알림 표시」 추가

다만 이 폼은 "점검 항목을 모두 확인하였다"는 **확인 서명**이 포함되어 있어,
점검 없이 태그만으로 서명이 제출된다. 방식 B를 권장하는 이유다.

### 질문 유형별 파라미터 형식 — 중요

같은 "날짜"라도 질문 **유형**에 따라 넣는 방법이 다르다.
0단계에서 복사한 링크에 실제로 어떤 형태가 들어있는지 보고 맞추면 된다.

| 질문 유형 | 파라미터 형식 | 예 |
|---|---|---|
| 단답형(짧은 답변) | `entry.ID=값` | `entry.123=2026-08-06` |
| **날짜** 질문 | `entry.ID_year` / `_month` / `_day` | `entry.123_year=2026&entry.123_month=8&entry.123_day=6` |
| **시간** 질문 | `entry.ID_hour` / `_minute` | `entry.456_hour=9&entry.456_minute=30` |
| 객관식·드롭다운 | `entry.ID=옵션텍스트` | `entry.789=출근` (옵션과 **글자까지 정확히** 일치) |

가장 다루기 쉬운 건 **단답형**이다. 폼을 직접 만들 수 있다면 날짜·시간 칸을
단답형으로 두는 쪽이 단축어가 훨씬 단순해진다.

## 방식 A. 백그라운드 자동 제출 (권장)

단축어 앱 → 우상단 `+` → 이름을 **"출입 기록"** 으로 변경.
아래 동작을 **순서대로** 추가한다. (동작 검색창에 큰따옴표 안 이름을 치면 나온다)

### ① 현재 날짜

- 동작: **"현재 날짜"** (Current Date)

### ② 날짜 포맷 지정 — 날짜 문자열 만들기

- 동작: **"날짜 포맷 지정"** (Format Date)
- 대상: `현재 날짜`
- 날짜 포맷: **사용자 설정** → 포맷 문자열 `yyyy-MM-dd`
- 시간 포맷: **없음**
- 결과 변수 이름을 **`날짜`** 로 바꾼다
  (결과를 길게 눌러 → "변수 이름 변경", 또는 **"변수 설정"** 동작으로 `날짜`에 저장)

### ③ 날짜 포맷 지정 — 시간 문자열 만들기

- 동작: **"날짜 포맷 지정"** 하나 더 추가
- 대상: **①의 `현재 날짜`** (②의 결과가 아님 — 반드시 ①을 다시 선택)
- 날짜 포맷: **없음**
- 시간 포맷: **사용자 설정** → 포맷 문자열 `HH:mm`  (24시간제. 오전/오후를 쓰려면 `a h:mm`)
- 결과 변수 이름을 **`시간`** 으로 지정

### ④ (선택) 출근/퇴근 자동 판별

같은 사원증을 아침·저녁 두 번 태그하므로, 정오 기준으로 자동 분기할 수 있다.

- 동작: **"날짜 포맷 지정"** → 대상 `현재 날짜`, 시간 포맷 사용자 설정 `HH`
  → 결과 변수 이름 **`시각`**
- 동작: **"만약"** (If) → 입력 `시각`, 조건 **"보다 작음"**, 값 `12`
  - 만약(참): **"변수 설정"** → 이름 `구분`, 값 `출근`
  - 아니면: **"변수 설정"** → 이름 `구분`, 값 `퇴근`
- **"만약 종료"**

> 판별 기준을 바꾸려면 `12`를 원하는 시각으로 수정한다.
> 이 단계를 건너뛰려면 아래 URL에서 `구분` 관련 파라미터를 지우면 된다.

### ⑤ 텍스트 — 제출 URL 조립

- 동작: **"텍스트"**
- 아래 내용을 **한 줄로** 입력한다. `entry.XXXX` 숫자는 0단계에서 알아낸 실제 ID로
  바꾸고, `날짜` `시간` `구분` 자리에는 **변수를 삽입**한다
  (키보드 위 변수 막대에서 해당 변수를 탭. 직접 글자로 타이핑하면 안 된다)

```
https://docs.google.com/forms/d/e/1FAIpQLSd6TI7M14M-mn_dqBStktVH9T4OxXl6zRfd17PbLRqqCFrW_A/formResponse?entry.1234567890=날짜&entry.987654321=시간&entry.555555555=구분&submit=Submit
```

- `viewform`이 아니라 **`formResponse`** 인 것에 주의. 이 차이가 "열기"와 "제출"을 가른다.
- 이름처럼 **항상 같은 값**이 있으면 `&entry.111111111=홍길동` 처럼 고정값으로 붙인다.
- 날짜/시간이 **날짜·시간 질문 유형**이면 위 표대로 바꿔 쓴다. 이 경우 ②③ 대신
  **"날짜 포맷 지정"** 을 `yyyy` / `M` / `d` / `H` / `m` 다섯 개로 나눠 만들고
  `...&entry.123_year=연&entry.123_month=월&entry.123_day=일&entry.456_hour=시&entry.456_minute=분` 형태로 조립한다.

### ⑥ URL 콘텐츠 가져오기 — 실제 제출

- 동작: **"URL 콘텐츠 가져오기"** (Get Contents of URL)
- URL: ⑤의 `텍스트` 변수
- 방법: **GET** (기본값 그대로)

### ⑦ 알림 표시 — 결과 확인

- 동작: **"알림 표시"**
- 내용 예: `출입 기록 완료 — 날짜 시간 구분` (변수 삽입)
- ⑥의 결과를 화면에 띄우지 않기 위해 **"결과 보기" 계열 동작은 넣지 않는다**

여기까지가 단축어 본체다. 상단 ▶︎ 재생 버튼으로 한 번 실행해 보고,
**구글 폼 응답 시트에 줄이 실제로 추가되는지 반드시 확인**할 것.

## 방식 B. 값이 채워진 폼 열기 (로그인 필요한 폼용)

사내 계정 로그인이 걸려 있거나 이메일을 자동 수집하는 폼은 방식 A가 실패한다
(단축어 요청에는 로그인 쿠키가 없기 때문). 이때는:

- ①~⑤까지 **똑같이** 만들되, ⑤ 텍스트의 주소를
  `.../viewform?usp=pp_url&entry....` 로 바꾼다 (`formResponse` → `viewform`,
  맨 뒤 `&submit=Submit`은 삭제)
- ⑥을 **"URL 콘텐츠 가져오기"** 대신 **"URL 열기"** (Open URLs)로 교체
- ⑦ 알림 표시는 삭제

결과: 태그하면 Safari가 열리고 **모든 칸이 이미 채워진 상태**로 뜬다. 제출 버튼만 누르면 끝.

## NFC 자동화 연결 — 사원증을 갖다 대면 실행

1. 단축어 앱 하단 **"자동화"** 탭
2. 우상단 **`+`** → 목록에서 **NFC** 선택
3. **"스캔"** 탭 → 사원증을 **아이폰 뒷면 상단**(카메라 부근)에 갖다 댄다
4. 인식되면 태그 이름을 **"사원증"** 으로 지정 → **다음**
5. 실행할 동작으로 **"출입 기록"** 단축어 선택
6. **"실행 전에 확인" 을 끈다** (iOS 17 이상에서는 **"즉시 실행"** 선택)
   - 이 설정을 안 끄면 태그할 때마다 확인 팝업이 떠서 "한 번에 입력"이 안 된다
7. (iOS 16 이하에 있는) **"실행 시 알림 표시"** 도 끄면 더 조용하다
8. **완료**

이제 사원증을 아이폰에 갖다 대면 → 날짜·시간이 채워진 채로 출입 이력이 기록된다.

### 사원증이 스캔되지 않는다면

아이폰은 **13.56MHz NFC** 카드만 읽는다. 구형 출입카드(125kHz RF 방식)나
암호화된 일부 사원증은 3단계에서 인식되지 않는다. 이 경우:

- **NFC 스티커**(NTAG213 등, 개당 수백 원)를 하나 사서 사원증 뒷면이나
  사원증 케이스 안에 붙이고, 그 스티커를 태그로 등록한다. 동작은 동일하다.
- 또는 자동화 트리거를 NFC 대신 **"회사 도착"(위치)** 이나 **"특정 Wi-Fi 연결"**
  로 잡아도 된다 (자동화 `+` → "도착" / "Wi-Fi").

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| 알림은 뜨는데 응답 시트에 안 들어감 | ⑤ 주소가 `viewform`으로 되어 있음 → **`formResponse`** 로 수정 |
| 응답은 들어가는데 칸이 비어 있음 | `entry.` 숫자가 틀림. 0단계 사전 입력 링크로 다시 확인 |
| 날짜/시간만 계속 빈칸 | 질문이 **날짜/시간 유형**인데 단답형처럼 보냈음 → `_year/_month/_day`, `_hour/_minute` 형식으로 변경 |
| 한글 값(출근/퇴근)이 깨지거나 빔 | ⑤ 앞에 **"텍스트 URL 인코딩"** 동작을 넣어 값만 인코딩하거나, 폼 옵션을 `IN`/`OUT` 같은 영문으로 변경 |
| 드롭다운 값이 안 들어감 | 폼의 옵션 텍스트와 **공백·글자가 완전히 동일**해야 함 |
| 로그인 페이지 HTML이 돌아옴 | 로그인 제한 폼 → **방식 B**로 전환 |
| 태그할 때마다 확인 팝업이 뜸 | NFC 자동화의 **"실행 전에 확인" / "즉시 실행"** 설정 확인 |
| 시간이 12시간제로 들어감 | ③ 시간 포맷을 `HH:mm`(대문자 H)로 — 소문자 `hh`는 12시간제 |
| 하루에 중복 기록됨 | ④ 분기 기준 시각 조정, 또는 "파일 가져오기/저장"으로 마지막 태그 시각을 저장해 5분 이내 재태그를 무시하도록 만들 것 |

## 참고: 완성된 URL 예시

0단계에서 알아낸 ID가 날짜 `1234567890`, 시간 `987654321`, 구분 `555555555`이고
2026-08-06 09:03에 출근 태그한 경우, 단축어가 실제로 호출하는 주소는 다음과 같다.

```
https://docs.google.com/forms/d/e/1FAIpQLSd6TI7M14M-mn_dqBStktVH9T4OxXl6zRfd17PbLRqqCFrW_A/formResponse?entry.1234567890=2026-08-06&entry.987654321=09:03&entry.555555555=출근&submit=Submit
```

이 주소를 브라우저 주소창에 그대로 붙여 넣어 실행해도 응답이 1건 접수된다.
**단축어를 만들기 전에 이 방법으로 먼저 테스트**하면 ID가 맞는지 바로 확인할 수 있다.
